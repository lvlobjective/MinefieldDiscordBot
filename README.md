# MinefieldDiscordBot Global-Included
Made for the wplace discord; a bot that allows mods to adds landmines that have a random chance of being triggered and timing out a user.

## Global-Included Version
This version includes Global mines. Global mines work *everywhere*, including in other servers, which is why this bot must be in **one server only** for the feature to work as intended. This is the version made for the WPlace server.

## Installation
1. Install Python on your platform of choice.
2. (Ideally) Create a virtual environment
3. `pip install disnake` to get disnake and dependencies
4. put token in the configuration at the beginning of the document.
5. `python bot.py` and you're done!
